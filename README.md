🔐 Ransomware Simulation

A simple Python-based ransomware simulation created for cybersecurity learning and experimentation.

⚠️ Disclaimer

This project is intended strictly for educational and authorized security research. Do not run it on systems or files you do not own or have explicit permission to test.

🎯 Purpose

The project demonstrates basic concepts behind ransomware, including:

File discovery

File encryption

Key generation

Decryption

It is designed to help understand how ransomware operates and why proper backups and endpoint security are important.

🛠️ Requirements

Python 3.x

Required Python packages listed in requirements.txt

🚀 Usage

Run the script only inside an isolated test environment such as a virtual machine with disposable files.

python malware.py 

📚 Learning Goals

This project is part of my cybersecurity and Python learning journey, focusing on understanding malware behavior from a defensive perspective.

Use responsibly.
